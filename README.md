# Jaringan Komputer 101

Repository ini berisi kumpulan materi, dokumentasi, dan file praktikum Jaringan Komputer menggunakan **Cisco Packet Tracer**.

## Daftar Isi

| No. | Modul | Materi |
|---|---|---|
| 01 | [Dasar Jaringan](./01-dasar-jaringan/) | Pengenalan perangkat dan topologi jaringan |
| 02 | [IP Addressing](./02-ip-addressing/) | Konfigurasi alamat IP dan subnet mask |
| 03 | [VLAN](./03-vlan/) | Konfigurasi Virtual LAN |
| 04 | [Inter-VLAN Routing](./04-inter-vlan-routing/) | Komunikasi antar-VLAN menggunakan router |

## Struktur Repository

Setiap folder modul berisi:
- `README.md` — penjelasan materi, tujuan, konfigurasi, dan hasil praktikum.
- File `.pkt` — simulasi jaringan Cisco Packet Tracer.
- `images/` — tangkapan layar topologi dan hasil pengujian, jika diperlukan.

## Tools

- Cisco Packet Tracer

## Catatan

File `.pkt` dapat diunduh dan dibuka menggunakan Cisco Packet Tracer. Beberapa file mungkin memerlukan penyesuaian berdasarkan versi aplikasi yang digunakan.
