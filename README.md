# Jaringan Komputer 101

Repository ini saya buat untuk mendokumentasikan pembelajaran dan praktikum Jaringan Komputer yang telah saya lakukan menggunakan Cisco Packet Tracer.

## Daftar Isi

| No. | Modul | Topik |
|---|---|---|
| 01 | [Basic Device Configuration](./modul01-basic-device-configuration/) | Konfigurasi dasar perangkat jaringan |
| 02 | [Switch Concept dan VLAN](./modul02-switch-concept-vlan/) | Konsep switching dan Virtual LAN |
| 03 | [Konfigurasi VLAN, Trunk, dan Inter-VLAN](./modul03-vlan-trunk-inter-vlan/) | Konfigurasi VLAN, trunk, dan komunikasi antar-VLAN |
| 04 | [Spanning Tree Protocol](./modul04-spanning-tree-protocol/) | Pencegahan loop pada jaringan Layer 2 |
| 05 | [EtherChannel](./modul05-etherchannel/) | Penggabungan beberapa link fisik menjadi satu logical link |

## Struktur Folder

Setiap folder modul berisi:
- `README.md` — penjelasan konsep, tujuan, langkah praktikum, konfigurasi, dan hasil pengujian.
- File `.pkt` — simulasi jaringan Cisco Packet Tracer.
- Gambar screenshot topologi dan hasil pengujian, jika diperlukan.

## Tools

- Cisco Packet Tracer

## Catatan

File `.pkt` dapat diunduh dan dibuka menggunakan Cisco Packet Tracer. Beberapa file mungkin perlu penyesuaian versi aplikasi. Hasil pengujian yang saya cantumkan berdasarkan praktikum yang telah saya lakukan.
